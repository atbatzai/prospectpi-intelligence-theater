## Lovable Integration Protocol

### **BMAD + Lovable Workflow**
This story uses a **hybrid approach** where Dev Agent handles logic/integration and Human handles UI generation:

**1. Dev Agent Role:**
- Sets up component structure, TypeScript interfaces, API integration
- Reaches UI generation task → **STOPS** and prompts human with exact Lovable instructions
- Waits for human to return with Lovable-generated component code
- Integrates Lovable component with backend systems and completes functionality

**2. Human Handoff Protocol:**
When Dev Agent reaches `[HUMAN HANDOFF]` tasks:
- Dev Agent provides: **Exact Lovable prompt section** + **Component specifications**
- Human: Opens Lovable → Uses provided prompt → Generates component → **Copies code back**
- Dev Agent: Continues with integration once code is provided
