# Story 1.4: Database Schema & User Management

## Status
Draft

## Story
**As a** ProspectPI Intelligence Theater system administrator  
**I want** a robust database schema with user management and dossier storage capabilities  
**so that** the platform can securely store user data, research requests, and generated intelligence dossiers

## Acceptance Criteria
1. PostgreSQL database schema for users, research requests, dossiers, and system tracking
2. User authentication system with secure password hashing and JWT token management
3. Research request persistence with full audit trail and status tracking
4. Dossier storage with structured intelligence sections and source attribution
5. API usage tracking and rate limiting data structures
6. Database migrations and seeding scripts for development and production
7. User organization management for enterprise accounts
8. Data retention policies and archival systems
9. Database performance optimization with proper indexing and connection pooling

## Dev Notes

### Database Architecture Overview
The database must support the complete Intelligence Theater workflow:
1. **User Management**: Authentication, organization membership, permissions
2. **Research Lifecycle**: Request tracking from submission to completion
3. **Dossier Storage**: Structured intelligence data with confidence scoring
4. **System Operations**: Usage tracking, performance monitoring, audit logs

#### Core User Management Tables
```sql
-- Users Table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    role VARCHAR(50) DEFAULT 'user',
    organization_id UUID REFERENCES organizations(id),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    last_login TIMESTAMP,
    is_active BOOLEAN DEFAULT true,
    email_verified BOOLEAN DEFAULT false,
    email_verification_token VARCHAR(255),
    password_reset_token VARCHAR(255),
    password_reset_expires TIMESTAMP
);

-- Organizations Table (Enterprise Support)
CREATE TABLE organizations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(200) NOT NULL,
    slug VARCHAR(100) UNIQUE NOT NULL,
    subscription_tier VARCHAR(50) DEFAULT 'starter',
    max_users INTEGER DEFAULT 5,
    max_requests_per_month INTEGER DEFAULT 100,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    is_active BOOLEAN DEFAULT true,
    billing_email VARCHAR(255),
    salesforce_org_id VARCHAR(100)
);

-- JWT Token Management
CREATE TABLE user_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    token_hash VARCHAR(255) NOT NULL,
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT NOW(),
    last_used TIMESTAMP DEFAULT NOW(),
    user_agent TEXT,
    ip_address INET,
    is_revoked BOOLEAN DEFAULT false
);
```

#### Intelligence Dossier Storage
```sql
-- Dossiers Table (Main Document)
CREATE TABLE dossiers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    request_id VARCHAR(50) UNIQUE NOT NULL REFERENCES research_requests(request_id),
    company_name VARCHAR(200) NOT NULL,
    confidence_score INTEGER NOT NULL,
    source_count INTEGER NOT NULL,
    generated_at TIMESTAMP DEFAULT NOW(),
    last_updated TIMESTAMP DEFAULT NOW(),
    classification VARCHAR(50) DEFAULT 'PROPRIETARY',
    export_count INTEGER DEFAULT 0,
    is_archived BOOLEAN DEFAULT false
);

-- Intelligence Sections (8 sections from Lovable spec)
CREATE TABLE intelligence_sections (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dossier_id UUID NOT NULL REFERENCES dossiers(id) ON DELETE CASCADE,
    section_type VARCHAR(50) NOT NULL, -- 'executive_summary', 'technology_intelligence', etc.
    title VARCHAR(200) NOT NULL,
    confidence_score INTEGER NOT NULL,
    last_updated TIMESTAMP DEFAULT NOW(),
    is_expanded BOOLEAN DEFAULT false,
    display_order INTEGER NOT NULL
);

-- Individual Intelligence Insights
CREATE TABLE intelligence_insights (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    section_id UUID NOT NULL REFERENCES intelligence_sections(id) ON DELETE CASCADE,
    finding TEXT NOT NULL,
    evidence JSON, -- Array of evidence strings
    confidence VARCHAR(20) NOT NULL, -- 'high', 'medium', 'limited'
    actionable_recommendation TEXT,
    sources JSON, -- Array of source references
    display_order INTEGER NOT NULL,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Data Sources Attribution
CREATE TABLE data_sources (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dossier_id UUID NOT NULL REFERENCES dossiers(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    type VARCHAR(50) NOT NULL, -- 'api', 'web_scraping', 'social', 'financial', 'news'
    last_updated TIMESTAMP NOT NULL,
    reliability DECIMAL(3,2) NOT NULL, -- 0.00 to 1.00
    url VARCHAR(500),
    api_response_time INTEGER,
    data_freshness_hours INTEGER
);
```

### Data Retention and Archival Policies
```sql
-- Data Retention Policies
-- Archive completed dossiers older than 2 years
CREATE OR REPLACE FUNCTION archive_old_dossiers()
RETURNS INTEGER AS $$
DECLARE
    archived_count INTEGER;
BEGIN
    UPDATE dossiers 
    SET is_archived = true
    WHERE generated_at < NOW() - INTERVAL '2 years'
    AND is_archived = false;
    
    GET DIAGNOSTICS archived_count = ROW_COUNT;
    RETURN archived_count;
END;
$$ LANGUAGE plpgsql;

-- Cleanup old WebSocket messages (keep 30 days)
CREATE OR REPLACE FUNCTION cleanup_websocket_messages()
RETURNS INTEGER AS $$
DECLARE
    deleted_count INTEGER;
BEGIN
    DELETE FROM websocket_messages
    WHERE created_at < NOW() - INTERVAL '30 days';
    
    GET DIAGNOSTICS deleted_count = ROW_COUNT;
    RETURN deleted_count;
END;
$$ LANGUAGE plpgsql;

-- Schedule cleanup jobs
CREATE EXTENSION IF NOT EXISTS pg_cron;
SELECT cron.schedule('archive-dossiers', '0 2 * * 0', 'SELECT archive_old_dossiers();');
SELECT cron.schedule('cleanup-websocket', '0 3 * * *', 'SELECT cleanup_websocket_messages();');
```
