# Story 1.2: REST API Endpoints & Request Handling

## Status
Done

## Story
**As a** ProspectPI Intelligence Theater frontend user  
**I want** secure REST API endpoints that process my research requests and return structured dossier data  
**so that** the Lovable frontend can seamlessly submit research requests and receive real-time intelligence results

## Acceptance Criteria
1. POST `/api/v1/research/generate-dossier` endpoint accepts ProspectResearchInput interface from Lovable frontend
2. Request validation ensures required fields (companyName) and validates optional field formats (URLs, character limits)
3. User authentication and authorization system integrated with JWT tokens
4. Database persistence for all research requests with unique requestId generation
5. Integration with Three-Agent Orchestration System (Story 1.1) for dossier generation
6. Structured API responses matching ResearchApiResponse interface for frontend consumption
7. Error handling with appropriate HTTP status codes and detailed error messages
8. Rate limiting and API usage tracking per user/organization
9. CORS configuration for Lovable frontend integration

**API Response Format:**
```typescript
// Success Response (202 Accepted)
{
  "success": true,
  "requestId": "req_abc123def456",
  "status": "processing",
  "estimatedCompletion": 480, // seconds
  "websocketUrl": "ws://api.prospectpi.com/ws/research/req_abc123def456",
  "message": "Research request accepted. Connect to WebSocket for real-time updates."
}

// Error Response (400 Bad Request)
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Company name is required",
    "details": {
      "field": "companyName",
      "constraint": "required"
    }
  }
}
```

### TypeScript Interfaces Implementation
[Source: docs/stories/lovable-prompt.md#key-typescript-interfaces]

```typescript
// Frontend Form Data Interface (INPUT)
interface ProspectResearchInput {
  companyName: string;                    // Required
  companyUrl?: string;                    // Optional
  linkedinUrl?: string;                   // Optional  
  crmNotes?: string;                      // Optional - max 1000 chars
  organizationFocus?: string;             // Optional
  locationOfInterest?: string;            // Optional
  contextLinks?: string[];                // Optional - array of URLs
  additionalContext?: string;             // Optional - max 2000 chars
}

// Backend API Payload Interface (INTERNAL)
interface ResearchApiPayload extends ProspectResearchInput {
  userId: string;
  requestId: string;
  timestamp: string;
  apiKeys: {
    theirstack: string;
    marketaux: string;
    coresignal: string;
    perplexity: string;
    linkedin?: string;
  };
}

// API Response Interface (OUTPUT)
interface ResearchApiResponse {
  success: boolean;
  requestId: string;
  status: 'processing' | 'complete' | 'error';
  estimatedCompletion?: number;
  websocketUrl?: string;
  message?: string;
  error?: {
    code: string;
    message: string;
    details?: any;
  };
}
```

### Request Validation Rules
[Source: docs/stories/lovable-prompt.md#required-research-inputs]

1. **companyName** (Required): Non-empty string, max 200 characters
2. **companyUrl** (Optional): Valid HTTP/HTTPS URL format
3. **linkedinUrl** (Optional): Must match LinkedIn company URL pattern
4. **crmNotes** (Optional): Max 1000 characters
5. **organizationFocus** (Optional): Max 100 characters
6. **locationOfInterest** (Optional): Max 100 characters
7. **contextLinks** (Optional): Array of valid HTTP/HTTPS URLs, max 5 URLs
8. **additionalContext** (Optional): Max 2000 characters

    created_at TIMESTAMP DEFAULT NOW(),

    success BOOLEAN
);
