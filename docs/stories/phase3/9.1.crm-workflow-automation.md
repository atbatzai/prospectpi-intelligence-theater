#  Story 9.1: CRM Workflow Automation

**Epic:** 9 - Enterprise Workflow Automation  
**Priority:** P0  
**Story Points:** 18  
**Sprint:** Track 2, Weeks 7-9

##  Story Description
As an **Enterprise Sales Team**, I want **bidirectional CRM integration** so that **dossier intelligence automatically syncs with Salesforce, HubSpot, and Pipedrive**.

##  Acceptance Criteria

### AC1: Salesforce Integration 
- OAuth 2.0 authentication with Salesforce
- Bidirectional sync: Account, Contact, Opportunity objects
- Auto-create dossiers when new Accounts added
- Push intelligence insights to Account/Opportunity fields
- Real-time webhook updates

### AC2: HubSpot Integration 
- API key + OAuth authentication
- Sync: Companies, Contacts, Deals
- Custom properties for intelligence data
- Automated workflow triggers
- Activity timeline integration

### AC3: Pipedrive Integration 
- API token authentication
- Sync: Organizations, Persons, Deals
- Custom fields mapping
- Deal stage automation triggers
- Note attachments for dossiers

### AC4: Workflow Automation Engine 
- Visual workflow builder (no-code)
- Triggers: CRM updates, dossier completion, schedule
- Actions: Create tasks, update CRM, send notifications
- Conditional logic and branching
- Error handling and retry logic

### AC5: Sync Status & Monitoring 
- Real-time sync status dashboard
- Conflict resolution (last-write-wins or manual)
- Sync error logging and alerts
- Data mapping configuration UI
- Rollback capability

##  Technical Requirements

### Integration Architecture
\\\	ypescript
interface CRMIntegration {
  provider: 'salesforce' | 'hubspot' | 'pipedrive';
  authenticate(): Promise<AuthToken>;
  syncToCRM(dossier: Dossier): Promise<SyncResult>;
  syncFromCRM(crmId: string): Promise<DossierUpdate>;
  handleWebhook(payload: any): Promise<void>;
}

class WorkflowEngine {
  createWorkflow(config: WorkflowConfig): Promise<Workflow>;
  executeWorkflow(workflowId: string, trigger: TriggerEvent): Promise<ExecutionResult>;
  monitorExecution(executionId: string): Promise<ExecutionStatus>;
}

### Database Schema
\\\sql
CREATE TABLE crm_connections (
  id UUID PRIMARY KEY,
  organization_id UUID,
  provider VARCHAR(50),
  auth_token_encrypted TEXT,
  config JSONB,
  status VARCHAR(50),
  last_sync TIMESTAMP
);

CREATE TABLE crm_sync_logs (
  id UUID PRIMARY KEY,
  connection_id UUID,
  direction VARCHAR(20),
  record_type VARCHAR(100),
  record_id VARCHAR(255),
  status VARCHAR(50),
  error_message TEXT,
  synced_at TIMESTAMP
);

CREATE TABLE workflow_definitions (
  id UUID PRIMARY KEY,
  name VARCHAR(255),
  trigger_type VARCHAR(100),
  trigger_config JSONB,
  actions JSONB,
  is_active BOOLEAN,
  created_by UUID
);
