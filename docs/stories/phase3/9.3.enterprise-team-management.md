#  Story 9.3: Enterprise Team Management & RBAC

**Epic:** 9 - Enterprise Workflow Automation  
**Priority:** P0  
**Story Points:** 24  
**Sprint:** Track 2, Weeks 10-12  
**Status:** READY FOR IMPLEMENTATION

##  Story Description
As an **Enterprise Administrator**, I want **granular role-based access control and team management** so that I can **control who accesses intelligence, manage usage quotas, and organize users across departments**.

##  Acceptance Criteria

### AC1: Role-Based Access Control (RBAC) 
**Given** enterprise organization  
**When** admin configures roles  
**Then** system supports roles: Admin, Manager, Analyst, Viewer  
**And** granular permissions for: view, create, edit, delete, share, export dossiers  
**And** custom role creation with permission matrix  
**And** role inheritance (Manager inherits Analyst permissions)  

### AC2: Department & Team Hierarchy 
**Given** multi-department organization  
**When** admin structures teams  
**Then** hierarchical organization: Org > Departments > Teams > Users  
**And** department-level quota allocation  
**And** team-level collaboration and sharing  
**And** cross-department visibility controls  

### AC3: User Provisioning & SSO 
**Given** enterprise SSO (SAML/OAuth)  
**When** user authenticates  
**Then** auto-provisioning based on email domain  
**And** role assignment via SAML attributes  
**And** JIT (Just-In-Time) user creation  
**And** SCIM 2.0 support for automated provisioning  

### AC4: Usage Quotas & Billing 
**Given** organization subscription plan  
**When** usage tracked  
**Then** org-level and user-level quotas enforced  
**And** real-time usage dashboard  
**And** soft limits (warnings) and hard limits (blocking)  
**And** quota overage alerts to admins  
**And** usage reports for billing purposes  

### AC5: Audit Logging & Compliance 
**Given** enterprise security requirements  
**When** any action performed  
**Then** comprehensive audit log recorded  
**And** logs include: user, action, timestamp, IP, resource  
**And** tamper-proof audit trail  
**And** exportable for compliance audits  
**And** retention policy (7 years default)  

##  Technical Requirements

### RBAC Architecture
\\\	ypescript
interface Role {
  id: string;
  name: string;
  permissions: Permission[];
  isCustom: boolean;
  organizationId: string;
}

interface Permission {
  resource: 'dossier' | 'user' | 'organization' | 'settings';
  action: 'create' | 'read' | 'update' | 'delete' | 'share' | 'export';
  scope: 'own' | 'team' | 'department' | 'organization';
}

class RBACService {
  async checkPermission(userId: string, resource: string, action: string): Promise<boolean>
  async assignRole(userId: string, roleId: string): Promise<void>
  async createCustomRole(name: string, permissions: Permission[]): Promise<Role>
  async getEffectivePermissions(userId: string): Promise<Permission[]>
}
\\\

### Database Schema
\\\sql
-- Roles Table
CREATE TABLE roles (
  id UUID PRIMARY KEY,
  organization_id UUID REFERENCES organizations(id),
  name VARCHAR(100),
  permissions JSONB,
  is_system_role BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW()
);

-- User Roles Junction
CREATE TABLE user_roles (
  user_id UUID REFERENCES users(id),
  role_id UUID REFERENCES roles(id),
  department_id UUID REFERENCES departments(id),
  assigned_by UUID REFERENCES users(id),
  assigned_at TIMESTAMP DEFAULT NOW(),
  PRIMARY KEY (user_id, role_id)
);

-- Departments Table
CREATE TABLE departments (
  id UUID PRIMARY KEY,
  organization_id UUID REFERENCES organizations(id),
  name VARCHAR(255),
  parent_department_id UUID REFERENCES departments(id),
  manager_user_id UUID REFERENCES users(id),
  monthly_quota INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Teams Table
CREATE TABLE teams (
  id UUID PRIMARY KEY,
  department_id UUID REFERENCES departments(id),
  name VARCHAR(255),
  lead_user_id UUID REFERENCES users(id),
  monthly_quota INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Team Members
CREATE TABLE team_members (
  team_id UUID REFERENCES teams(id),
  user_id UUID REFERENCES users(id),
  joined_at TIMESTAMP DEFAULT NOW(),
  PRIMARY KEY (team_id, user_id)
);

-- Audit Logs
CREATE TABLE audit_logs (
  id UUID PRIMARY KEY,
  organization_id UUID,
  user_id UUID,
  action VARCHAR(100),
  resource_type VARCHAR(100),
  resource_id UUID,
  details JSONB,
  ip_address INET,
  user_agent TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_audit_logs_org ON audit_logs(organization_id, created_at DESC);
CREATE INDEX idx_audit_logs_user ON audit_logs(user_id, created_at DESC);
CREATE INDEX idx_audit_logs_resource ON audit_logs(resource_type, resource_id);
